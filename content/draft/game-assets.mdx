# 游戏素材网站

如果你是做游戏开发（Unity、Unreal、Godot、网页游戏等），素材网站大致可以分为：

* 2D 美术素材
* 3D 模型素材
* 音效 / 音乐
* 动画与角色
* 综合素材市场
* 免费开源资源站

## 综合素材市场

### Unity Asset Store

[访问 Unity Asset Store](https://assetstore.unity.com?utm_source=chatgpt.com)

适合：

* Unity 项目
* UI
* 特效
* 插件
* 角色模型
* 地图场景

特点：

* 资源数量非常大
* 经常打折
* 可以直接导入 Unity

---

### Fab (Epic Games)

[访问 Fab (Epic Games)](https://www.fab.com?utm_source=chatgpt.com)

Fab 是 Epic 把多个市场整合后的平台：

* 原 Unreal Marketplace
* Sketchfab Store
* Quixel Megascans

特点：

* Unreal 官方市场
* 大量高质量 PBR 模型
* AAA 级场景资源

---

### itch.io Assets

[访问 itch.io Assets](https://itch.io/game-assets?utm_source=chatgpt.com)

特点：

* 独立开发者最喜欢
* 大量低价和免费资源
* 像素风资源特别丰富

适合：

* Game Jam
* Indie Game
* 2D RPG

## 2D 游戏素材

### Kenney Assets

[访问 Kenney Assets](https://kenney.nl/assets?utm_source=chatgpt.com)

特点：

* 完全免费
* CC0 许可证
* 可商用

非常适合：

* 新手学习
* 原型开发
* Game Jam

---

### OpenGameArt

[访问 OpenGameArt](https://opengameart.org?utm_source=chatgpt.com)

特点：

* 最大免费游戏素材社区之一
* 包含：

  * 音乐
  * 音效
  * 贴图
  * UI
  * 精灵图

注意：

* 不同素材许可证不同
* 商用前需要查看授权

---

### CraftPix

[访问 CraftPix](https://craftpix.net?utm_source=chatgpt.com)

特点：

* RPG素材丰富
* 卡通风格多
* 免费+付费

常见资源：

* RPG角色
* NPC
* 技能图标
* 地图素材
