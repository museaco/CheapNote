## 方式二：带过滤


```bash
from huggingface_hub import snapshot_download

if __name__ == '__main__':

    # 1. 定义你要筛选的文件夹通配符
    # 这里的 "文件夹名/*" 表示只下载该文件夹下的所有内容
    filters = [
        "hunyuan3d-delight-v2-0/*",
        "hunyuan3d-dit-v2-0/*",
        "hunyuan3d-paint-v2-0/*"
    ]

    print("开始打包下载指定的三个模型...")

    # 2. 只需调用一次，把大仓库拉下来
    snapshot_download(
        repo_id="tencent/Hunyuan3D-2",  # 假设这是总仓库 ID
        local_dir="./tencent/Hunyuan3D-2",  # 下载到本地的总目录
        allow_patterns=filters,
    )

    print("✨ 过滤下载完成！")

```

## 方式三：命令行

```bash
hf download tencent/Hunyuan3D-2 --include "hunyuan3d-dit-v2-0/*" --local-dir ./tencent/Hunyuan3D-2
hf download tencent/Hunyuan3D-2 --include "hunyuan3d-paint-v2-0/*" --local-dir ./tencent/Hunyuan3D-2
hf download tencent/Hunyuan3D-2 --include "hunyuan3d-delight-v2-0/*" --local-dir ./tencent/Hunyuan3D-2
```
