# Vim 基础

Vim 是 Linux 最常用的文本编辑器。

## 打开文件

```bash
vim app.py
```

---

## 三种模式

```text
普通模式 (Normal Mode)
    │
    ├── i ──> 编辑模式 (Insert Mode)
    │
    └── : ──> 命令模式 (Command Mode)
```

### 普通模式

打开文件后默认在普通模式。

### 进入编辑模式

```text
i
```

按 `i` 键进入编辑模式，可以像正常编辑器一样输入文字。

---

## 退出编辑

```text
Esc
```

按 `Esc` 回到普通模式。

---

## 命令模式操作

在普通模式下按 `:` 进入命令模式。

### 保存退出

```vim
:wq
```

| 命令 | 全称 | 说明 |
|------|------|------|
| `:w` | write | 保存 |
| `:q` | quit | 退出 |
| `:wq` | write + quit | 保存并退出 |
| `:q!` | quit force | 不保存强制退出 |
| `:wq!` | write + quit force | 强制保存退出 |

### 不保存退出

```vim
:q!
```

### 只保存不退出

```vim
:w
```

## 常用操作

### 移动光标

| 按键 | 说明 |
|------|------|
| `h` | 左 |
| `j` | 下 |
| `k` | 上 |
| `l` | 右 |
| `gg` | 跳到文件开头 |
| `G` | 跳到文件末尾 |
| `:n` | 跳到第 n 行（如 `:10` 跳到第10行） |

### 删除

| 按键 | 说明 |
|------|------|
| `x` | 删除当前字符 |
| `dd` | 删除当前行 |
| `3dd` | 删除3行 |

### 复制粘贴

| 按键 | 说明 |
|------|------|
| `yy` | 复制当前行 |
| `3yy` | 复制3行 |
| `p` | 粘贴到光标下方 |

### 撤销/重做

| 按键 | 说明 |
|------|------|
| `u` | 撤销 (undo) |
| `Ctrl + r` | 重做 (redo) |

## 搜索

```vim
/keyword
```

向下搜索 `keyword`。

```vim
?keyword
```

向上搜索。

| 按键 | 说明 |
|------|------|
| `n` | 下一个匹配 |
| `N` | 上一个匹配 |

## 实用场景

### 编辑配置文件

```bash
vim /etc/nginx/nginx.conf
```

1. 按 `i` 进入编辑模式
2. 修改内容
3. 按 `Esc`
4. 输入 `:wq` 保存退出

### 编辑后不保存退出

1. 按 `Esc`
2. 输入 `:q!`

### 查看文件但不编辑

```bash
vim app.py
```

用方向键或 `hjkl` 浏览，按 `:q` 退出。
