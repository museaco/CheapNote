如果你的目标是 **Python 后端开发 + AI 应用开发**，达到能够独立开发项目、找到初中级岗位或者接私活的水平，可以按下面的知识树学习。

---

# 第一阶段：Python 基础（必会）

这是所有后端和 AI 的基础。

### 1. Python 语言

必须熟练掌握：

* 基本语法
* 函数
* 类与对象
* 继承、多态
* 装饰器
* 生成器
* 迭代器
* 上下文管理器（with）
* 异常处理
* typing 类型提示

例如：

```python
from typing import Optional

def get_user(id: int) -> Optional[str]:
    return "Alex"
```

---

### 2. Python 标准库

重点掌握：

```python
os
pathlib
json
datetime
time
logging
uuid
hashlib
base64
collections
asyncio
threading
multiprocessing
```

特别是：

```python
pathlib
asyncio
logging
```

工作中经常使用。

# 第二阶段：Web 后端开发

建议直接学习 FastAPI。

## 1. HTTP基础

理解：

* GET
* POST
* PUT
* DELETE
* PATCH

状态码：

```text
200
201
400
401
403
404
500
```

理解：

* Header
* Cookie
* Session
* Token
* JWT

---

## 2. FastAPI

必须掌握：

```python
FastAPI
APIRouter
Depends
Middleware
```

例如：

```python
@app.get("/users")
def get_users():
    return []
```

---

### 3. Pydantic

FastAPI 核心。

```python
from pydantic import BaseModel

class User(BaseModel):
    name: str
    age: int
```

必须会：

* 数据校验
* 类型转换
* 嵌套模型

---

### 4. 异步编程

理解：

```python
async
await
```

例如：

```python
@app.get("/")
async def home():
    return {"ok": True}
```

# 第三阶段：数据库

## 1. MySQL

```sql
UPDATE
```

## 2. ORM

SQLModel


* 缓存

