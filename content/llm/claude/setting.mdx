## 跳过登录验证

编辑或新建 ~/.claude.json（Windows 路径：C:\Users\<用户名>\.claude.json），将 hasCompletedOnboarding 设为 true，跳过 Anthropic 官方登录验证。

 
```json
{
  "hasCompletedOnboarding": true
}
```
